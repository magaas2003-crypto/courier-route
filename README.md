# Маршрут курьера

Веб-приложение для iPhone: загружаете скриншоты со списком доставок → приложение
находит адреса → вы указываете, где находитесь → получаете порядок объезда по
дорогам → «Поехать» открывает точку в навигаторе → «Следующий адрес» отмечает
доставку и открывает следующую точку.

## Что внутри и что реально работает

| Часть | Как сделано | Ключ нужен? |
|---|---|---|
| Распознавание скриншотов | Tesseract.js прямо в браузере телефона, русский язык. Картинки никуда не отправляются. | Нет |
| Разбор адреса | Улица, дом, корпус, строение, квартира, подъезд, этаж; исправление латинских букв после OCR | — |
| Повторы | Точные повторы (перекрывающиеся скриншоты) пропускаются; заказы в одном доме можно объединить в одну остановку | — |
| Поиск адресов на карте | **Яндекс Геокодер** (если задан ключ) или **Nominatim / OpenStreetMap** (бесплатно, без ключа) | По желанию |
| Время и расстояния по дорогам | **OSRM** — матрица «каждая точка с каждой» по реальной дорожной сети | Нет |
| Порядок объезда | До 12 адресов — точный оптимум; больше — эвристика (2-opt + перенос участков) с перезапусками. Учитывает окна доставки «с … до …» | — |
| Карта (по кнопке, не грузится сама) | Leaflet + OpenStreetMap: старт, пронумерованные точки, линия маршрута, всплывающие подсказки | Нет |
| Навигация | Яндекс Навигатор, Яндекс Карты, Apple Карты, 2ГИС, Google Карты, Waze — через их официальные ссылки | Нет |
| Работа без сети | Список, порядок и кнопки «Поехать» сохраняются в телефоне и работают офлайн | — |

**Ограничения, о которых нужно знать:**

- **Пробки не учитываются** при выборе порядка. OSRM считает время свободного движения. Пробки на каждом отрезке учитывает сам навигатор, когда ведёт вас к точке. Сервисы матриц с пробками (например, Яндекс Router / Distance Matrix, 2ГИС Distance Matrix) платные и требуют договора — подключение возможно отдельно.
- **Навигаторы получают одну точку за раз** (от вашего текущего места до следующего адреса). Это честное поведение: Яндекс Навигатор по официальной ссылке строит маршрут к одной точке. Нужный порядок держит приложение, а кнопка «Следующий адрес» переключает точки.
- При переходе по ссылкам `yandexnavi://`, `yandexmaps://`, `dgis://` Safari каждый раз спрашивает «Открыть в приложении?» — это защита iOS, обойти её нельзя. Apple Карты, Google Карты и Waze открываются без вопроса.
- Распознавание настроено под список «Доставка → Список» приложения Wildberries для курьеров: адрес на 2–3 строки, «под.», «дмф.», «этаж», плашки «Ожидает доставки» / «Забрать возвраты», «Новая Москва», сёла и города области. Для лучшего результата делайте скриншоты в режиме «Список», с перекрытием при прокрутке — повторы отбросятся сами.
- Общедоступные серверы OSRM и Nominatim — бесплатные демо-серверы с ограничениями (Nominatim — не чаще 1 запроса в секунду, поэтому 20 адресов находятся примерно за 20–25 секунд). Для личной работы их хватает; при сбоях приложение предлагает повторить или построить приблизительный порядок с явной пометкой.

## Два режима работы

- **С сервером** (Render «Web Service», VPS): ключи хранятся на сервере, браузер их не видит. Рекомендуется.
- **Без сервера** (GitHub Pages, Render «Static Site», Netlify, открыт файл index.html): приложение само это замечает
  и обращается к 2ГИС, OpenStreetMap и OSRM напрямую с телефона. Ключ 2ГИС вводится в «Настройках» и хранится
  только на этом устройстве. Если «Проверить поиск адресов» пишет, что браузер не пустил запрос к 2ГИС, —
  нужен режим с сервером.

## Как запустить, чтобы пользоваться с iPhone

Приложению нужен сервер с **https** — без https iPhone не даст определить местоположение.
Нужен только Node.js 18 или новее, сторонних пакетов нет.

### Вариант 1. Render.com (проще всего, без своего компьютера)

1. Создайте аккаунт на github.com. Нажмите **New repository**, назовите `courier-route`, создайте.
2. В репозитории нажмите **Add file → Upload files** и перетащите все файлы из архива (папки `public`, `test`, файлы `server.js`, `package.json`, `README.md`). Нажмите **Commit changes**.
3. Зайдите на render.com, войдите через GitHub. **New → Web Service** → выберите репозиторий `courier-route`.
4. Настройки: Runtime — **Node**, Build Command — оставьте пустым (или `npm install`), Start Command — `npm start`. Тариф — бесплатный, если доступен.
5. В разделе **Environment** нажмите **Add Environment Variable**: имя `DGIS_KEY`, значение — ваш ключ 2ГИС. Там же можно добавить `APP_PASSWORD` (см. ниже). Нажмите **Create Web Service**.
   Ключ не вставляйте в файлы проекта и не загружайте в GitHub.
6. Через пару минут появится адрес вида `https://courier-route-xxxx.onrender.com`. Откройте его в Safari на iPhone → кнопка «Поделиться» → **«На экран „Домой“»**. Приложение появится иконкой.

На бесплатных тарифах сервер «засыпает» без запросов, и первое открытие после перерыва может занять до минуты. Если это мешает, подойдёт платный тариф или любой VPS.

### Вариант 2. Свой сервер / VPS

```bash
node server.js            # слушает порт из переменной PORT, по умолчанию 3000
```
Поставьте перед ним любой https-прокси (Caddy, nginx + Let's Encrypt).

### Проверка

После запуска откройте сайт → «Настройки» → **«Проверить поиск адресов»**. Должно появиться «✅ 2ГИС: нашёл дом». Если «ключ отклонён» — проверьте, что ключ вставлен без пробелов и активен в кабинете 2ГИС.

Для разработчика:

```bash
npm test   # 27 тестов разбора адресов (включая реальный формат Wildberries) и оптимизатора + 13 тестов сервера с имитацией сервисов
```

## Переменные окружения (секреты — только на сервере)

| Переменная | Зачем | Обязательно |
|---|---|---|
| `YANDEX_GEOCODER_KEY` | Ключ Яндекс Геокодера. Точнее находит московские корпуса и строения, чем OpenStreetMap | Рекомендуется (нужен ключ Яндекса или 2ГИС) |
| `DGIS_KEY` | Ключ 2ГИС (Geocoder API). Можно вместе с Яндексом: если один не нашёл дом, спросит другой | Рекомендуется (нужен ключ Яндекса или 2ГИС) |
| `APP_PASSWORD` | Код доступа: без него чужие люди, узнавшие адрес сайта, не смогут тратить ваши лимиты. Код вводится один раз в «Настройках» приложения | Рекомендуется |
| `CONTACT_EMAIL` | Ваш e-mail для заголовка запросов к Nominatim (их правила просят указывать контакт) | Желательно |
| `OSRM_URL` | Свой сервер OSRM вместо общедоступного | Нет |
| `NOMINATIM_URL` | Свой сервер Nominatim | Нет |

Ключи хранятся только в переменных окружения сервера. Браузер обращается к вашему
серверу (`/api/...`), а сервер — к Яндексу. В код страницы ключ не попадает.

### Как получить ключ Яндекс Геокодера

1. Откройте кабинет разработчика: https://developer.tech.yandex.ru/ (войдите через Яндекс ID).
2. **Подключить API** → выберите **«JavaScript API и HTTP Геокодер»** → заполните анкету.
3. Скопируйте ключ и вставьте его в переменную `YANDEX_GEOCODER_KEY` на Render (Environment → Add) — не в файлы проекта.
4. Проверьте на странице сервиса действующие условия и бесплатный лимит запросов: Яндекс может требовать платную лицензию при коммерческом использовании.

Без ключа приложение работает на OpenStreetMap — бесплатно, но часть домов (особенно корпуса, новостройки, Новая Москва, область) там отсутствует.

### Как получить ключ 2ГИС

1. Откройте https://platform.2gis.ru/ и войдите (или зарегистрируйтесь).
2. Получите ключ для **Geocoder API** (обычно сначала выдаётся демо-ключ для проверки; действующие условия и лимиты смотрите в кабинете).
3. Вставьте ключ в переменную `DGIS_KEY` на сервере.

### Порядок поиска адреса

Сервер спрашивает сервисы по очереди: **Яндекс → 2ГИС → OpenStreetMap** (только те, для которых есть ключ; OpenStreetMap — всегда).
Как только какой-то сервис нашёл точный дом, поиск останавливается. Если точного дома нет нигде, приложение показывает найденные варианты
(ближайшие к вам — первыми) и кнопку «Найти в Яндекс Картах». Для OpenStreetMap дополнительно пробуются разные записи:
«улица Ферганская» / «Ферганская улица», «8 к3» / «8к3» / «8 корпус 3». Если адрес из «Новой Москвы» не нашёлся с округом,
приложение повторит запрос без округа и района.

## Как пользоваться

**Автоматический режим (включён по умолчанию):** нажмите «Загрузить скриншоты» — приложение само
определит ваше местоположение по GPS, найдёт адреса и построит маршрут. Нажатий больше не нужно,
кроме уточнения адресов, которые нашлись неоднозначно. Новый адрес — маршрут пересчитается сам
от вашего текущего места. Карта не загружается, пока не нажмёте «Показать карту».
Выключить автоматику можно в «Настройках».

Пошагово вручную:

1. **Загрузить скриншоты** — можно выбрать несколько сразу. В первый раз загружается словарь русского языка (~10 МБ), потом он берётся из памяти телефона.
2. Проверьте список: зелёное «Найден» — всё в порядке; оранжевое «Уточните» — выберите правильный вариант или нажмите «На карте» и отметьте дом. Маршрут в неуточнённую точку не строится.
3. **Время** у адреса — окно доставки «не раньше / не позже». Срочные адреса встанут раньше; если не успеваете, время прибытия станет красным.
4. **Определить моё местоположение** (или адрес, или точка на карте) → **Построить оптимальный маршрут**.
5. Внизу панель текущей доставки: **Поехать** — открыть навигатор; **Доставка выполнена** — отметить и остаться в приложении; **Следующий адрес** — отметить текущий выполненным и сразу открыть следующий в навигаторе; **Пропустить**, **Вернуться позже** (в конец очереди), **Отменить** последнее действие.
6. Добавили адрес после построения — появится плашка **«Пересчитать от текущего места»**: порядок оставшихся точек пересчитается от вашего GPS, выполненные доставки сохранятся.
7. Навигатор выбирается в **Настройках** (иконка справа вверху). Там же время на одну доставку для расчёта прибытия.

Пользуйтесь экраном только на безопасной остановке.
